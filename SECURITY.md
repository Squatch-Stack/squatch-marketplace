# Security

Report a security problem to security@squatch.cc. Please do not open a public issue for it.

Every change here is reviewed in a private repository first, must pass a secret scan of the full history and a check
for private paths and addresses, and arrives as a signed commit. The plugins in this marketplace only point at remote
MCP servers we run (https://mcp.squatch.cc/mcp, https://petnecto.com/mcp); they install no local code.
