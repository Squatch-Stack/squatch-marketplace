# Security

Report a security problem to security@squatch.cc. Please do not open a public issue for it.

Changes are reviewed in a private repository before they are published here. The public `main` branch requires signed
commits and does not allow force-pushes or deletion (a repository ruleset). The plugins in this marketplace point at
remote MCP servers we run (https://mcp.squatch.cc/mcp, https://petnecto.com/mcp) and install no local code.
